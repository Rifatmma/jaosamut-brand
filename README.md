# Jaosamut — portfolio

Public case study: the JAOSAMUT brand identity, the Khao Hom character sheet and the UI kit.
Designed by Rif-at Wanwang.

- Fully static (`output: 'export'`): no server, no API, no database, no login. Nothing here can reach the POS.
- Content is a **redacted copy** of the private brand pages in the POS repo, produced by `scripts/sync.py`:
  no downloads, logos and mascot shown as WebP (vector masters stay private), drafts/open fixes, halal/JAKIM notes,
  merch drop counts and research links removed, menu trimmed to 4 sample dishes.

Update after the private pages change (run inside this folder, not the POS repo):

```bash
npm run release
```
